Der vollständige Dateiüberblick steht in der [Repository-Map](REMOMAP.md). Die [AGENTS.md](AGENTS.md) enthält die Regeln für Arbeiten in diesem Repository.

| Ordner | Inhalt |
| --- | --- |
| [docs/](docs/) | Produkt, Technik, Benutzerhandbuch, Wettbewerb, Marketing und Recht |
| [assets/](assets/) | Screenshots und PDF-Dokumente |
| [beispiele/twx/](beispiele/twx/) | TWX-Beispielarchiv |

Die Dateien dokumentieren unterschiedliche Stände. Versionsnummern und Datumsangaben sind keine Bestätigung des aktuellen Produktverhaltens.
